
# Cryptoria.bg

**Bitcoin-first media and open-source projects from Bulgaria.**

Cryptoria.bg is an independent Bulgarian digital media platform focused on Bitcoin, cryptocurrency news, blockchain technology, education, and research.

Our mission is to make Bitcoin and related technologies more accessible through reliable information, educational resources, and useful open-source tools.

## Our Open-Source Projects

### Cryptoria Sats Converter

A WordPress plugin designed to help users convert between Bitcoin (BTC), satoshis (sats), EUR and USD.

The project is available through the official WordPress Plugin Directory.

[View Cryptoria Sats Converter on WordPress.org](https://wordpress.org/plugins/cryptoria-sats-converter/)
